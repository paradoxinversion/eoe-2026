The Main screen of the Dashboard presents the player with at-a-glance vital information about the world and their Empire.

## Primary Sections

### Main Header

The Main Header appears at the very top of the Main Screen. It displays the current in-game date and the 'Bide Time' buttons, which ends the current turn.

#### Bide Time Buttons

There are three buttons for players to end their turn and bide time.

- 1 Day
- 1 Week

These buttons should attempt to pass the amount of time listed, however, the player can technically only wait until the last day of the month. For instance, if a player clicks the button to bide time for a week and the month ends in 2 days, waiting will stop in 2 days instead of a week.

### Resources

The Resources section contains widgets that show quick and basic information about the state of the Empire.

#### EVIL

The EVIL widget displays the empire's current amount of EVIL.

#### Money

The Money widget displays the empire's current amount of Money.

#### Science

The Science widget displays the empire's current amount of accrued Science.

#### Infrastructure

The Infrastructure widget displays the empire's current infrastructure load and total infrastructure capacity, ie, (15/20)

#### Control

The Control widget displays the total amount of zones controlled by the empire and the total amount of zones in the world, ie, (3/10)

#### Intelligence

The Intelligence widget displays the average intelligence level of every Zone.

#### Captives

The Captives widget displays the total amount of Agents/People the Empire has imprisoned

#### Infirmed

The Infirmed widget displays the total amount of empire Agents currently in a hospital

### Operations

The Operations section displays information about activities that empire Agents are participating in and Plots that are queued for execution.

#### Activities List

The Activities List is a simple immutable table. Each row displays the following information:

- The name of the activity
- The total amount of activity participants

#### Plot Queue

The Plot Queue is a table. Each row displays the following data:

- The plot's name
- The total amount of plot participants
- IF the plot has a target zone, the target zone

### Events

The Events section displays a list of Game Events that have occured, in chronological order (latest first).
