The personnel screen is where the player views and manages their Agents.

## Primary Sections Sections

### Main Header

The top of the Personnel Screen displays a row of information widgets

#### Agents

The Agents widget displays the total amount of empire Agents

#### Agent Capacity

The Agent Capacity widget displays the current amount of empire Agents and the maximum allowed, ie, (20/100). Below this value, it shows a percentage of the capacity, ie, 20%.

### Agent List

The Agent List is a table shows all the Empire's Agents. Each row shows:

- The Agent's code name
- The Agent's role
- The Agent's current and total health, ie, (20/20)
- A 'Profile' button to open the Agent's profile

When the player clicks the Profile button on a row, a modal window opens and displays a Profile with the relevant Agent selected.
