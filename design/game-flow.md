# Game Flow

## Starting the game

When a player opens the game, they are presented with the Title Screen. When they click the New Game button, they are taken to the Character Generation Screen.

On the Character Generation screen, players must:

- Input their Overlord's First Name and Last Name

When all fields have been completed, the Start Game button becomes active. When the player clicks the Start Game button, the world is generated and the player is taken to Main screen of the Dashboard.

## Using the Dashboard

> The Dashboard is the interface through which the player interacts with the game.

There is a Sidebar on the left side of the Dashboard that the player will use to navigate to different screens. The buttons in the Sidebar are: Main, Intelligence, Personnel, Economy, Infirmary, Captives, and Settings.
