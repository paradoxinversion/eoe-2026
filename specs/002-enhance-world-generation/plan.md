# Implementation Plan: Enhance World Generation — Zones, People, Buildings, Orgs

**Branch**: `002-enhance-world-generation` | **Date**: 2026-01-19
**Spec**: [spec.md](spec.md)

## Summary

Add deterministic post-terrain entity generation that instantiates `Zone`, `Person`, `Building`, and `GoverningOrganization` model instances using the canonical frontend models. Each Zone is a fixed-size grid tile and MUST contain at least one instance of each configured building type. Outputs include a debug JSON artifact and unit/integration tests that validate determinism and referential integrity.

## Technical Context

- Language/Version: TypeScript (frontend codebase)
- Primary Dependencies: Vite, React, Vitest, AJV (for schema validation)
- Storage: in-repo debug JSON artifacts (tests); runtime persistence unchanged
- Testing: Vitest for unit/integration; AJV for contract/schema validation
- Target Platform: Browser (local-first developer machines)
- Project Type: Frontend feature implemented under `frontend/src/services` and `frontend/src/models`
- Performance Goals:
    - Generation p95: < 2s for a default map (100×100 tiles) on a modern developer laptop; p99: < 5s.
    - Memory budget during full generation: < 200MB.
    - Execution requirement: run off the main UI thread or in incremental chunks that yield to the event loop every 100ms (chunk size ≤ 500 tiles).
    - CI measurement: include a synthetic benchmark script that measures p95; CI must fail if p95 regression > 20% vs baseline.
- Constraints: Must use canonical model types in `frontend/src/models/*` and building types from `frontend/src/models/building.ts`.

## Constitution Check

- **I. Code Quality & Maintainability**: Compliant — changes confined to `frontend/src/services/generation.ts` and model files; PR will include focused changes and docs.
- **II. Test-First & Automated Testing**: Compliant — unit tests and integration tests will be added; AJV schema validation will be included in tests.
- **III. User Experience Consistency**: Compliant — generation runs offline and emits debug artifacts for QA; no blocking UI changes.
- **IV. Performance & Resource Constraints**: Compliant — generator runs deterministically and is designed to run in background; will add a note if profiling indicates regressions.
- **V. Local-First & Portability**: Compliant — feature is local-only and does not require hosted services.
