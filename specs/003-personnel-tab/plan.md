## Summary

Deliver the Personnel Tab UI (frontend-only) that displays agent capacity widgets, a circular breakdown chart by Agent Type, a browsable Agent list with a "Focus" action, and a reusable `Profile` component for Agents and People. Approach: implement frontend components under `frontend/src/components/personnel`, add services to compute AgentTypeSummary and chain-of-command capacity using existing `frontend/src/services` patterns, and add tests (unit + integration + a11y). Data persistence uses existing IndexedDB helpers in `frontend/src/services/persistence.ts`.
